## 📸 Add a Preview Screenshot *(makes repo card look 10x better)*

1. Open your live site
2. Take a screenshot (full browser window)
3. Save it as `preview.png`
4. Upload it to the same repo folder
5. The README will auto-show it ✨

## 🚀 How To Update Your Existing GitHub Repo *(web upload, no terminal)*

Since you already uploaded via the website:

1. Go to your repo on **github.com**
2. Click on each file → **pencil icon** (Edit) → paste the new contents → **Commit changes**
   - Do this for `index.html`, `style.css`, `script.js`
3. For `README.md`:
   - Click **Add file → Create new file**
   - Name it `README.md` → paste contents → Commit
4. For `preview.png`:
   - Click **Add file → Upload files** → drag the screenshot → Commit
5. Wait ~1 minute → refresh `https://YOUR-USERNAME.github.io/YOUR-REPO/`

> ⚠️ If you see the **old heart animation**, do a **hard refresh** (`Ctrl + Shift + R` / `Cmd + Shift + R`). GitHub Pages caches aggressively.

## 🎛️ Fun Things To Tweak (try these!)

In `script.js`, change `CONFIG`:

| Change | Effect |
|--------|--------|
| `particleCount: 5000` | Denser, richer galaxy |
| `arms: 2` | Classic two-arm spiral |
| `arms: 6` | Flower-like pattern |
| `spin: 0.4` | Fast whirling |
| `colorInner: [255, 100, 200]` | Pink/neon core |
| `colorOuter: [80, 255, 180]` | Green outer arms |
| `mouseForce: 4` | Mouse violently repels stars |
